Parameter Guide

            
说明书

          

          
        


        

          

            
输入

            

              
主提示词

              
你真正想要的画面。写主体、动作、场景、用途，比只写风格更稳定。

              
参考图 / 图生图

              
上传后会自动走图生图。适合重绘、换风格、保留构图或主体身份。

              
最终提示词

              
平台把你的各个参数合成为真正发给模型的完整指令。

            

          


          

            
核心参数

            

              
用途

              
告诉平台这张图最终拿来干什么，比如产品图、论文图、Logo 或信息图。

              
风格

              
控制整体视觉方向，比如电影感、写实、动漫、商业产品或矢量友好。

              
比例

              
先定画面方向，比如 16:9 横屏、9:16 竖屏或 1:1 方图；会写进最终提示词。

              
尺寸

              
auto 让模型自己选尺寸；固定尺寸会同时影响像素、比例和清晰度，4K 竖屏可选 2160 x 3840。

              
质量

              
auto 由模型判断；high 更精细但更慢，low 更快但细节少。

              
格式

              
PNG 适合清晰图和文字；JPEG 适合照片；WebP 文件更小。

            

          


          

            
输出控制

            

              
变体

              
一次生成几张候选图。数量越多，等待时间和额度消耗越高。

              
压缩

              
主要影响 JPEG / WebP 的体积和画质，数值越高通常越清晰也越大。

              
透明背景

              
要求生成可抠图/透明背景倾向的图；适合贴纸、图标、产品主体。

              
默认 / auto / opaque

              
默认是不额外指定背景；auto 让模型决定背景策略；opaque 明确要求不透明背景。

            

          


          

            
细化项

            

              
主体 / 场景

              
主体写“画谁/画什么”，场景写“在哪里”。这两项最影响画面内容。

              
构图 / 镜头

              
构图控制远近和摆放；镜头控制视角、焦段、微距、俯拍等摄影感。

              
光照 / 情绪 / 色彩

              
控制画面的气氛。比如柔光、冷静、黑白红点缀会显著改变观感。

              
精确文字

              
图片里必须出现的文字。模型仍可能写错，短词比长句更可靠。

              
不要出现

              
负面约束。适合排除水印、低清、杂乱背景、变形手等问题。

            

          


          

            
生成方式

            

              
生成提示词

              
只刷新最终提示词，不消耗生图额度。

              
加入自动队列

              
把任务排进本地队列，平台会按顺序自动调用 Codex 生图。

              
Codex 生成

              
立即调用本机 Codex 登录额度生图，并在进度区显示执行状态。

              
API 生成

              
使用 OPENAI_API_KEY 直连 Images API；没有配置密钥时按钮会禁用。
